Platform team

Define a golden path once: repo layout, CI, infrastructure, observability and policy. Version it like any other code.

# paths/node-service.yaml
name: node-service
version: 4.2.0
ci: [lint, test --coverage 80, sbom]
deploy:
  strategy: canary
  verify: { error_rate: "< 0.5%", p95: "< 300ms" }
require:
  - owner
  - oncall
  - slo
